# 🧠 Deep Learning Practice

This repository is dedicated to exploring and practicing key concepts, architectures, and techniques in Deep Learning.
It contains hands-on experiments, small projects, and notes that help strengthen understanding of neural networks and modern AI techniques.

## 📘 Overview

The goal of this repository is to learn by doing — implementing deep learning models from scratch and using frameworks like TensorFlow and PyTorch.
Each notebook or script focuses on a specific concept or problem, such as image classification, natural language processing, or optimization techniques.

| Category                 | Tools / Libraries          |
| ------------------------ | -------------------------- |
| Programming Language     | Python 🐍                  |
| Deep Learning Frameworks | TensorFlow, Keras, PyTorch |
| Data Handling            | NumPy, Pandas              |
| Visualization            | Matplotlib, Seaborn        |
| Development Environment  | Jupyter Notebook / VS Code |
